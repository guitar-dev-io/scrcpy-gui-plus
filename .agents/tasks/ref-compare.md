# Structural comparison vs the reference brief

Palette differs by design (Caveat A: navy + coral on the app's themed shell). Compared from screenshots at 1920x1080 and 1366x768 (web build, empty and 14-item seeded Library). The reference image itself was not re-opened in this step; the brief's layout list was used.

| Brief element | Observed | Status |
|---|---|---|
| 5 nav cards/tabs | Create, Templates, Device Actions, Tools, Library as a pill tablist in the header (tabs, not large cards) | Parity in count; presentation is tabs |
| Header device selector | Present at right ("No device connected" select) beside Saved / Links counters | Parity |
| 3-column Create | At 1366: form + Live Preview visible as two columns, third (aside) not seen in the viewport; 1920 not re-inspected for the third column | Partial / unverified |
| Library folders/tags sidebar | Left rail (All, Uncategorized, Favorites, Recent, Trash, Folders + add) at wide width; collapses to a Folder select at 1280 | Parity |
| Search + type filter row | Search, sort, Tags, Manage tags, grid/list toggle, type chips | Parity |
| Card grid | Cards with Favorite, Download PNG, Copy, Actions menu | Parity |
| "Showing a-b of N items" | Present ("Showing 1-8 of 13 items") | Parity |
| Details panel | Right column at wide widths; Drawer below the column threshold (1280 container) | Parity |
| Status line | Footer text and "Requires the desktop app" notes present | Parity |

Known gaps: heading contrast in light theme (verification F1); header wraps to two rows at 1366x768.
